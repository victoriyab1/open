# Китайский каждый день — личный Telegram-бот

Python-бот для упрощённого китайского HSK 1. Полный актуальный экзаменационный список HSK 3.0: **300 слов**, программа опубликована в ноябре 2025 года, введена с июля 2026 года. Это экзаменационная редакция, отличающаяся от списка на 500 слов из стандарта 2021 года.

## Что умеет

- При первом запуске предлагает русский или английский язык и часовой пояс. Настройки можно менять.
- Ежедневно в 12:00 местного времени присылает 3 новых слова, перевод, пиньинь со знаками тонов и простой пример с переводом и пиньинем.
- Сначала показывает карточки, затем предлагает начать сопоставление: для каждого слова отдельно выбрать перевод и отдельно пиньинь из трёх вариантов.
- После ответа помечает правильный вариант ✅ и ошибочный ❌. Повторной попытки нет; кнопка «Дальше» продолжает урок.
- После новых слов даёт до 2 слов на повторение. Выбирает только слова с наступившим сроком, случайно, с повышенным весом накопленных ошибок. Очередь допускается.
- Верно в обоих вопросах: повтор через 3 дня, затем через 7 дней, далее каждые 7 дней. Ошибка хотя бы в одном вопросе: завтра. Одно решение по слову считается один раз за пару вопросов.
- «Архивировать слово» исключает его из повторения; `/archive` → «Повторять» возвращает с ближайшим сроком завтра.
- `/lesson` продолжает сегодняшний урок. После завершения запускает дополнительную практику без новых слов. Ранний правильный ответ в практике не переносит срок повторения; ошибка возвращает слово на завтра.
- Озвучивает китайские слова по кнопке. Это синтезированная речь gTTS, без платного API. Запись кешируется в Telegram. При недоступности сервиса бот сообщает об этом и сохраняет прогресс.
- Пропущенные даты не создают дополнительные порции новых слов. После окончания словаря продолжается повторение.
- Работает только с заданным Telegram ID владельца и только в личном чате.

## Запуск на Mac / Linux

Нужен Python 3.12 или новее. В терминале откройте папку проекта:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python configure.py
.venv/bin/python manage.py poll
```

`configure.py` запрашивает токен скрытым вводом, определяет ваш Telegram ID через одноразовую команду вашему боту и создаёт `.env` с правами `600`. Если строки Neon пока нет, используется локальный SQLite. Не публикуйте `.env` и файлы базы.

На Mac вместо первых трёх команд можно дважды нажать `setup.command` в Finder: он создаст окружение, установит библиотеки и откроет настройку. Python 3.12+ должен быть установлен заранее. Для последующей локальной работы запустите `manage.py poll` командой выше.

В локальном режиме программа должна работать постоянно, компьютер должен быть включён и подключён к интернету. `poll` сам проверяет время рассылки. Чтобы перейти на webhook, остановите `poll`, настройте сервер и выполните `manage.py set-webhook`.

**Размещение без карты:** [пошаговая инструкция](docs/DEPLOYMENT_RU.md) для Render Free + Neon Free + cron-job.org. В проект включены `render.yaml` и скрипт создания задания Cron. Аккаунты и секреты настраиваются отдельно; наличие исходников не означает, что бот уже опубликован.

Если плагин Neon недоступен, создайте проект на бесплатном плане через Neon Console, откройте Connect и скопируйте pooled Connection string. Запустите `connect-neon.command` двойным щелчком: он скрыто примет строку, проверит подключение и обновит только `DATABASE_URL` в `.env`.

Render также поддерживает Secret Files. Если настройки загружены секретным файлом с собственным именем, добавьте обычную переменную `BOT_ENV_FILE=/etc/secrets/ИМЯ_ФАЙЛА` — программа прочитает его без вывода значений в логи. Например, для файла `NiHao`: `BOT_ENV_FILE=/etc/secrets/NiHao`.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Первый запуск или справка |
| `/lesson` | Сегодняшний урок или дополнительная практика |
| `/settings` | Язык и часовой пояс |
| `/language` | Русский / English |
| `/timezone Asia/Shanghai` | Любой пояс из базы IANA |
| `/archive` | Архив и возврат слов |
| `/stats` | Прогресс, ошибки, ожидающие повторения |
| `/pause`, `/resume` | Остановить / включить рассылку |
| `/privacy` | Какие данные хранятся |
| `/delete_me` | Удалить настройки и прогресс с подтверждением |

Первый урок выдаётся сразу после выбора языка и часового пояса. Если вы уже начали урок вручную до полудня, повторная порция в 12:00 не отправляется. Дни считаются по выбранному часовому поясу. Один и тот же день при повторном выборе пояса не выдаёт новую порцию повторно.

## Проверка

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Тесты проверяют учебные сценарии, интервалы, часовые пояса и переход на летнее время, защиту доступа, повторные запросы, постоянное хранение и очередь доставки. Telegram и облачная база требуют отдельной проверки после подключения реальных секретов.

## Устройство проекта

- `hsk_bot/engine.py` — учебная логика, расписание и подбор слов.
- `hsk_bot/app.py` — защищённые webhook и HTTP-вход для Cron.
- `hsk_bot/storage.py` — PostgreSQL для сервера, SQLite для локального запуска; состояние и очередь сохраняются атомарно.
- `hsk_bot/telegram.py` — Telegram Bot API, доставка, озвучка.
- `data/hsk1.json` — готовые 300 карточек. `data/content.tsv` — редактируемые авторские переводы и примеры.
- `data/hsk1-source.json`, `data/provenance.json` — словарь из официальной программы и информация об источнике.
- `scripts/build_curriculum.py` — воспроизводимая сборка карточек из PDF и исходного содержимого; на сервере не запускается.

Источник состава слов: [HSK — официальный сайт](https://www.chinesetest.cn/Development?lang=cn), раздел «考试大纲». Пиньинь слов взят из этой программы. В примерах используется словарное написание тонов; в живом произношении возможны изменения тонов. Учебные примеры и переводы подготовлены для этой программы; перед публикацией для широкой аудитории стоит провести редакторскую проверку преподавателем.

## Ограничения первой версии

Бесплатный хостинг не гарантирует доставку строго в секунду: возможны задержки и остановка при исчерпании квот. При двух повторениях и трёх новых словах очередь повторений будет расти. Авария между принятой Telegram отправкой и фиксацией в базе может повторить сообщение: Bot API не предоставляет ключ идемпотентности для отправки. Результат задания при повторном нажатии не засчитывается повторно.

Для облачного варианта используйте **один worker, один thread и один экземпляр сервиса**. Метаданные расписания кешируются в памяти, чтобы минутные проверки Cron не расходовали постоянно квоту Neon. Прогресс и очередь доставки всегда остаются в базе. Конфигурацию базы напрямую во время работы не меняйте — используйте команды бота или перезапустите сервис.
